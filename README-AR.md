# تحويل لعبة الشطرنج إلى APK

## المتطلبات (مرة واحدة)
- Node.js 22 أو أحدث
- Android Studio (يثبّت Android SDK و JDK تلقائياً)

## بناء التطبيق
1. فك الضغط ثم افتح الطرفية داخل المجلد وشغّل:  npm install
2. شغّل:  npx cap sync android
3. شغّل:  npx cap open android   (يفتح Android Studio)
4. انتظر انتهاء Gradle Sync، ثم من القائمة:
   Build > Build Bundle(s) / APK(s) > Build APK(s)
5. ستجد الملف في:  android/app/build/outputs/apk/debug/app-debug.apk
   انقله إلى الهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

لتجربة مباشرة على هاتف موصول بالكيبل: اضغط Run في Android Studio.

## اللعب بدون إنترنت (الهوتسبوت)
1. اللاعب الأول: يفعّل الهوتسبوت من إعدادات هاتفه، ثم يفتح اللعبة ويضغط «فتح نقطة لعب».
   يظهر له عنوان IP (غالباً 192.168.43.1 أو يشبهه).
2. اللاعب الثاني: يتصل بشبكة الهوتسبوت، يفتح اللعبة، يكتب العنوان في خانة «عنوان IP»، ويضغط «اتصال».
3. الأول يلعب بالأبيض والثاني بالأسود.
إذا كان الاثنان على نفس راوتر واي فاي، يعمل بنفس الطريقة بعد أن يكتب الثاني عنوان هاتف الأول.

## اللعب أونلاين برمز غرفة
يعمل عبر Firebase (مشروع chess-5432e) ويتطلب إنترنت وقواعد Firestore المذكورة سابقاً.

## تعديل اللعبة
عدّل الملف www/index.html ثم أعد: npx cap sync android
